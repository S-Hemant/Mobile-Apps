# PulseTrack - Mobile Fitness Tracker 🏃‍♂️✨

PulseTrack is a modern, high-performance mobile fitness tracking application featuring an **Aurora Glassmorphic** UI design system built with React Native and Expo.

## Features

- 🌌 **Aurora Glass UI**: Sleek translucent cards, ambient gradients, vibrant accent colors, and dark/light mode support.
- 🏋️ **Workout Logging**: Track strength exercises (sets, reps, weight) and cardio activities (duration, distance, calories).
- 📈 **Stats & Analytics**: Real-time progress tracking, weekly activity summaries, and streak calculations.
- 🥗 **Nutrition & Macro Tracking**: Log meals (breakfast, lunch, dinner, snacks) with calorie, protein, carbohydrate, and fat metrics.
- 💤 **Sleep Monitoring**: Log sleep cycles, bedtime, wake time, and sleep quality ratings.
- 🎯 **Goals & Milestones**: Set and track personalized fitness goals across distance, calories, workouts, and steps.
- 👤 **Profile & Achievements**: User level progression, streak counter, and customizable preferences.

## Tech Stack

- **Framework**: React Native with Expo SDK 52
- **Language**: TypeScript
- **Navigation**: React Navigation (Bottom Tabs & Native Stack)
- **Styling**: Aurora Glass theme, Linear Gradient (`expo-linear-gradient`), BlurView (`expo-blur`)
- **Icons**: Expo Vector Icons (`@expo/vector-icons`)
- **State**: React Context API with offline-first persistence

## Getting Started

### Prerequisites

- Node.js (v20+)
- npm or yarn
- Expo Go mobile app (iOS or Android)

### Installation

```bash
# Clone the repository
git clone https://github.com/S-Hemant/Mobile-Apps.git

# Navigate into the project
cd Mobile-Apps

# Install dependencies
npm install

# Start the Expo development server
npx expo start
```

Scan the QR code in your terminal with the Expo Go app (Android) or the default Camera app (iOS) to run the application on your physical device.
